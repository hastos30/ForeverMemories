Версия — patch (0.4.2), а не minor: это часть этапа v0.4.0 Polish («доступность»), новых функций съёмки нет.
Офлайн: 49/49 PASS. Клиент: **PENDING**.

Проверка в игре:
1. Навести мышь на любую галочку, кнопку, «- / +», выпадающий список, вкладку слева — справа появляется подсказка: золотой заголовок и белый текст с переносом строк.
2. Навести на подпись галочки (текст справа от квадрата) — та же подсказка; клик по подписи переключает галочку.
3. События: навести на «Редкий противник» — в подсказке красная строка «недоступно: …» с причиной. Клик по названию события выбирает его (галочка не переключается).
4. Профили: навести на «Кинематограф» — описание пресета. Журнал: навести на фильтр «Все статусы» — расшифровка статусов.
5. Подсказка исчезает, когда мышь уходит; не остаётся на экране после закрытия окна или кадра в чистом режиме.
6. `/reload` с русским языком — подсказки на русском; с английским — на английском.

## 0.4.1-beta — баг «кнопки выбора не открывают список»
Причина: виджет `W.Cycle` был задуман как «клик = следующее значение», без списка. Заменён на
`W.Dropdown` (UI/Widgets.lua): своя рамка со списком, общая для всех выпадающих кнопок.
Смена языка: сохраняется сразу в `ForeverMemoriesDB.settings.locale`, затем диалог
«Перезагрузить / Позже» → `ReloadUI()` только по согласию.
Офлайн: 47/47 PASS. Клиент: **PENDING** — проверить по списку ниже.

Проверка в игре:
1. Настройки → Язык: появляется список из 3 пунктов; выбор «Русский» → диалог; «Позже» → после `/reload` язык русский.
2. Повтор с «Перезагрузить»: интерфейс перезагружается сам, язык применён.
3. Захват → Режим / Таймер, Главная → Профиль, Правила → Режим, Журнал → 4 фильтра, ручная панель: список открывается, выбор сохраняется (после `/reload` тоже, кроме фильтров журнала и ручной панели — они временные).
4. Список закрывается: клик мимо, Esc, закрытие окна, смена вкладки.
5. Фильтр «Событие» в журнале (много пунктов) — список в 2 колонки, не уходит за край экрана.

## Что проверять по ходу игры
1. При входе: нет красных окон ошибок; окно выбора пресета; `/fm` открывает окно.
2. Новый уровень: 2 кадра, интерфейс на миг пропадает и возвращается, уведомление «Воспоминание сохранено».
3. Новая зона: 1 кадр через ~2 с после входа в зону.
4. Эпическая добыча, маунт, босс подземелья — по одной записи в журнале.
5. Бой во время «чистого» кадра: интерфейс возвращается сразу. Если нет — `/fm ui` и сообщить.
6. Вкладка «Диагностика» → строка «Недоступные события»: прислать, если там что-то кроме RARE, REPUTATION, BG, PROFESSION.

## Допущения 0.4.0 без проверки в клиенте
- `UIParent:Hide()/Show()` вне боя разрешены; `PLAYER_REGEN_DISABLED` приходит до блокировки (можно показать UI).
- События `NEW_MOUNT_ADDED`, `LFG_COMPLETION_REWARD`, `QUEST_TURNED_IN`, `PLAYER_GUILD_UPDATE`, `UPDATE_SHAPESHIFT_FORMS`, `CHAT_MSG_SYSTEM` есть в Forever (если нет — триггер станет «недоступно», без ошибки Lua).
- Ссылки на предметы: качество через `C_Item.GetItemQualityByID` или код цвета ссылки.
- `ReloadUI()` можно вызвать из кода аддона по клику в диалоге (0.4.1; `/reload` работает — S7). Если нет — сообщение в чат «введите /reload».
- Подсказки (0.4.2): `GameTooltip:AddLine(text, r, g, b, true)` переносит длинный текст; `HookScript` не ломает шаблоны кнопок; при скрытии окна под мышью приходит `OnLeave`; обычная рамка с `EnableMouse(true)` получает `OnEnter` (побочный эффект: окно нельзя тянуть за строки настроек — только за пустые места и заголовок).
- Выпадающий список: `SetFrameStrata("FULLSCREEN_DIALOG")`, `SetClampedToScreen`, `Texture:SetColorTexture`, слой `HIGHLIGHT` у кнопки (0.4.1).
- Шаблоны `UIPanelButtonTemplate`, `UICheckButtonTemplate`, `InputBoxTemplate`, `UIPanelCloseButton`, `BackdropTemplate` есть в клиенте.
- Счётчики лимитов «за час» живут в памяти сессии и обнуляются при `/reload`.
- TTL запроса отсчитывается от момента, когда истекла его задержка (ТЗ не уточняет).

## Найденные противоречия и решения

1. **Interface не указан в ТЗ.** Взят `16001` по Warcraft Wiki. Подтвердить по 4-му значению `GetBuildInfo()` (`/fm status`).
2. **Forever работает на Mainline API (12.1.5), а не на Classic.** По данным сообществ combat log аддонам недоступен, GUID обфусцированы, часть значений — secret values. Риск для триггеров RARE (нужно знать, что убит редкий противник), BOSS вне `ENCOUNTER_END`, DUEL, BG. Решение: не гадать, проверить отдельные события в v0.1.0/v0.2.0; неподдерживаемые показывать как недоступные (как и требует ТЗ).
3. **`SCREENSHOT_*` не содержат payload.** Нативный Print Screen неотличим от нашего снимка. Решение (уже в ТЗ): один активный запрос, таймаут 5 с, карантин 5 с, чужие сигналы только считаются.
4. **Приоритет MANUAL = 0**, а редактор в UI_DESIGN допускает 1–4. Предложение: 0 — служебное значение только для ручного кадра, в редакторе не показывается. Требует согласия автора.
5. **`tests/` и `docs/` внутри папки аддона** (ARCHITECTURE §2) vs «релиз ZIP с корректной корневой папкой» (v1.0.0). Решение: при сборке релиза исключать `tests/`, `docs/`, `*.md` кроме README/LICENSE.
6. **Схема данных ARCHITECTURE §5** пока не реализована: spike хранит данные в `ForeverMemoriesDB.spike`. В v0.1.0 — миграция, `spike` удаляется.
7. **`/fm` без аргументов должен открывать окно**, а окна в v0.0.1 нет. Временно показывает справку.
8. **ROADMAP требует ветку/PR на каждый этап**, но GitHub-репозитория у проекта нет. Сейчас файлы лежат в папке проекта. Первый коммит, когда появится репозиторий: `feat: add v0.0.1 spike with manual screenshot and API probe`, тег `v0.0.1`.
