хранение даты получения), блок в Обзоре, карточка на Главной, подраздел «Достижения».

Решения:
- «Месяц назад» / «год назад» — та же дата календаря; если её нет (31 → февраль, 29 февраля),
  воспоминаний нет. Для годовщин такая дата сдвигается на последний день месяца (иначе
  годовщина пропала бы).
- «Посещённые зоны» для «Исследователя» — все ключи `visited` (как «Посещено локаций» в
  Истории). Региональные достижения и «Знаток Азерота» требуют подтверждённого каталога
  (названия из клиента или английский клиент); без него — «Каталог зон не подтверждён».
- «Игровые дни» — дни с любой записанной игрой (как серия в Рекордах).
- Дата получения записывается только при выполнении во время игры. Первое включение
  засчитывает накопленный прогресс как «дата неизвестна» (`done[id] = 0`). Для других
  персонажей (просмотр) ничего не записывается: выполненное по данным показывается без даты.
- Годовщина занимает место третьего последнего снимка: окно не стало выше.

  снимки или локации). Дата самой долгой сессии известна только для сессий с 0.12.0
  («Дата неизвестна» для более старого рекорда).

  3 мин его сбрасывает). Без него — последняя активная секунда с пометкой.

## 0.5.1 — длина шага 1,5 м
Отчёт автора из игры: «делаю шаг, а временами добавляет 1,5–2». Причина — формула ТЗ (0,75 м):
