# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии: [SemVer](https://semver.org/lang/ru/).

## [0.4.2-beta] — 2026-11-24 (в клиенте не проверено)

### Added
- Подсказки при наведении мыши на каждый элемент окна: галочки, выпадающие списки, «- значение +», кнопки, поля ввода, вкладки, строки событий, журнала и профилей, ручная панель, окно первого запуска, кнопка в Options → AddOns. Заголовок — название пункта, ниже — что он делает и когда срабатывает. RU и EN.
- Подсказка строки события объясняет, что его вызывает, а для недоступного события — почему оно недоступно.
- Подсказки пресетов описывают, что именно снимает каждый пресет.
- Виджет `W.Tooltip(widget, text, title)` (UI/Widgets.lua); текст и заголовок могут быть функциями.

### Changed
- Клик по подписи галочки переключает её (как в настройках игры). Исключение — список событий: там клик по названию выбирает событие для редактора.
- Подсказка кнопки у миникарты: добавлена строка про перетаскивание и скрытие.
- 49 офлайн-тестов (было 47): у каждого элемента есть подсказка без «сырых» ключей; недоступное событие объясняет причину.

## [0.4.1-beta] — 2026-11-24 (в клиенте не проверено)

### Fixed
- Кнопки выбора (язык, режим съёмки, таймер, профиль, режим правила, фильтры журнала, ручная панель) теперь открывают выпадающий список вариантов, а не переключают значение по кругу. Список закрывается выбором, повторным кликом, кликом мимо, Esc или закрытием окна.

### Changed
- Смена языка сохраняется сразу и показывает диалог «Перезагрузить / Позже». `ReloadUI()` вызывается только после согласия игрока; вопрос не задаётся, если видимый язык не меняется.
- 47 офлайн-тестов (было 44): выпадающий список, сохранение выбора, согласие на перезагрузку.

## [0.4.0-beta] — 2026-11-24 (функции v0.1.0–v0.4.0, в клиенте не проверены)

По решению автора этапы v0.1.0–v0.4.0 собраны в одну бета-версию без игровой проверки между этапами.
Логика покрыта офлайн-тестами (44 теста, mock API); проверка в Forever — по ходу игры.

### Added
- Автосъёмка по событиям: новый уровень, максимальный уровень, первая зона, босс, эпическая и легендарная добыча, маунт, подземелье (LFG), дуэль, смерть, выбранное задание, гильдия, форма друида, путешествие (интервал), случайный кадр, ручной кадр.
- Режимы normal / clean / dual, серии 1–5 кадров, деградация clean → normal в бою, восстановление UI при входе в бой.
- Очередь на 20 запросов с приоритетами, объединением событий (0.5 с), дедупликацией (10 с), TTL, лимитами (час / сессия / путешествие).
- Журнал (до 2000 записей, избранное до 500), фильтры, пагинация по 50, заметки, удаление записи.
- Пресеты Minimalist, Explorer, Adventurer, Cinematic, Archivist и пользовательские профили; профиль для всех или для персонажа.
- Основное окно с вкладками, кнопка у миникарты, ручная панель с таймером, Addon Compartment, страница в Options → AddOns, горячие клавиши.
- Уведомления, Капсула времени (первый и последний кадр дня), Anniversary при входе.
- Русский и английский языки.
- Команды `/fm on|off|toggle|shot|status|debug|log|ui|panel|quest`.

### Changed
- Схема данных v2 (ARCHITECTURE.md §5), автоматическая миграция с v0.0.1.

### Not implemented (недоступно с причиной в UI)
- RARE: нет журнала боя у аддонов в Forever.
- REPUTATION, BG, PROFESSION: надёжный сигнал клиента ещё не подтверждён.
- Подпись кадра (опциональная по ТЗ).

## [0.0.1] — 2026-11-24

Проверено в клиенте World of Warcraft: Forever 1.60.1 (71037): см. API_COMPATIBILITY.md.

### Added
- Минимальный TOC для World of Warcraft: Forever (`Interface: 16001` по документации, требует подтверждения).
- Ручной снимок `/fm shot`: одна операция за раз, результат только по `SCREENSHOT_SUCCEEDED/FAILED`, иначе `unconfirmed` через 5 с и карантин 5 с.
- `/fm status`, `/fm debug`, `/fm log` для диагностики.
- Проба API: наличие функций, регистрация событий-кандидатов, счётчики срабатываний (без payload).
- SavedVariables `ForeverMemoriesDB` с проверкой типов и восстановлением повреждённых данных.
- Офлайн-тесты логики на mock API (`lua5.1 tests/run.lua`).
- PROGRESS.md, API_COMPATIBILITY.md.
