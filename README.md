# ForeverMemories

Аддон для **World of Warcraft: Forever**: автоматические скриншоты важных моментов.
Сейчас это технический прототип **v0.0.1** — только ручной снимок и проверка API.

Техническое задание: [docs/](docs/). Ход работ: [PROGRESS.md](PROGRESS.md).

## Установка (v0.0.1)
1. Закройте игру.
2. Скопируйте папку `ForeverMemories` в `World of Warcraft\_forever_\Interface\AddOns\`
   (имя папки клиента проверьте у себя: путь взят из документации сообщества).
   Внутри должен лежать `ForeverMemories.toc`, а не ещё одна папка.
3. Запустите игру, на экране выбора персонажа → «Модификации» → включите ForeverMemories.

## Команды
- `/fm shot` — сделать снимок
- `/fm status` — состояние и последние 5 снимков
- `/fm debug` — какие функции и события есть в клиенте
- `/fm log` — последние 20 строк журнала

## Тесты без игры
```
lua5.1 tests/run.lua
```
