# Тестирование и приёмка (v0.5.0, дополнено в v0.6.0, v0.8.0, v0.9.0 и v0.10.0)

Два уровня:
1. **Офлайн** — `lua5.1 tests/run.lua`: логика на поддельном клиенте (tests/mock_wow.lua) с
   управляемыми часами. Доказывает логику, но **не** поведение настоящего Forever.
2. **Клиент** — ручная проверка в Forever. Для каждой: сборка, шаги, результат, PASS/FAIL/SKIP.
   SKIP ≠ PASS. Результаты — в API_COMPATIBILITY.md и PROGRESS.md.
