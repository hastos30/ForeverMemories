# Тестирование и приёмка
Автотесты чистой Lua-логики через mock API и управляемые часы; клиентские тесты отдельно на актуальной сборке Forever. Для каждого теста фиксировать сборку, шаги, ожидаемый/фактический результат, PASS/FAIL/SKIP и доказательство. SKIP не означает PASS.

| ID | Сценарий | Ожидание |
|---|---|---|
| T01 | Чистая установка, вход | Нет Lua-ошибок, defaults применены |
| T02 | Ручной /fm shot | Один вызов, реальный файл, корректный статус |
| T03 | Новый уровень | Правило запускает указанное число кадров |
| T04 | Отключить событие | Нет автоматического кадра |
| T05 | Повтор одного key за cooldown | Один запрос |
| T06 | Уровень и максимум одновременно | Только MAX_LEVEL |
| T07 | Совместимые события | Один запрос, все причины в журнале |
| T08 | Несовместимые режимы | Не объединяются |
| T09 | Очередь заполнена | Ограничена, корректное вытеснение |
| T10 | Истёк TTL | Нет устаревшего кадра |
| T11 | Вход в бой до clean | normal fallback, UI не скрыт |
| T12 | Вход в бой во время подготовки | Безопасная отмена/восстановление |
| T13 | Загрузка или смена мира | Нет кадра загрузки, очередь очищена/просрочена |
| T14 | Ошибка Screenshot | Ошибка в журнале, UI восстановлен |
| T15 | Нет сигнала результата | Таймаут, unconfirmed, нет повторной съёмки |
| T16 | Поздний callback | Не изменяет новый запрос |
| T17 | Dual/серия | Последовательные кадры, восстановление между ними |
| T18 | UI был скрыт до съёмки | Не показывать его самовольно |
| T19 | Пауза в серии | Нет последующих автоматических кадров |
| T20 | Ручной кадр на паузе | Работает при безопасном состоянии |
| T21 | AFK/карта/бой в Journey | Интервальная съёмка пропущена |
| T22 | Достигнут лимит | Автоматические вызовы прекращаются |
| T23 | Reload и смена персонажа | Настройки/история сохранены, профили изолированы |
| T24 | Повреждённая конфигурация | Безопасное восстановление defaults |
| T25 | Переполнение журнала | Лимит соблюдён, избранное защищено по политике |
| T26 | Неподдерживаемый API | Триггер недоступен, нет Lua-ошибки |
| T27 | RU/EN, длинные строки | Нет обрезанных важных элементов |
| T28 | Нативный Print Screen параллельно | Не обещать ложную корреляцию, документировать ограничение |
| T29 | Длительная сессия 2 часа | Нет роста очереди/таймеров без границ, нет постоянного OnUpdate |
| T30 | Удаление записи журнала | Файл снимка не удаляется |

Критерии MVP: T01–T05, T09–T16, T19–T20, T22–T24, T26 и T29 для реализованных возможностей; остальные обязательны перед релизом соответствующих функций. Измерить CPU/память на одном клиенте с аддоном и без него при сопоставимой нагрузке, документировать результаты; не выдумывать универсальный порог. Блокеры релиза: потеря управления/UI, съёмка без включённого правила (кроме manual), необработанные Lua-ошибки, ложное заявление об успехе, несовместимость с целевым клиентом. Проверять фактические файлы в каталоге скриншотов вручную.
