# Тестирование

[English](TESTING.en.md) · **Русский**

Главное правило: функция считается работающей, только когда она проверена в клиенте
Forever. Офлайн-тест доказывает, что Lua выполняется без ошибок, но не то, как это
выглядит и работает в игре.

## 1. Офлайн (без игры)
Нужен `lua5.1`. Запуск из корня аддона:

| Команда | Что проверяет | Состояние (1.0.0-beta.17) |
|---|---|---|
| `lua5.1 tests/smoke.lua` | Аддон грузится, все вкладки и страницы Истории/Настроек открываются на обоих языках, все файлы из `UI/Media.lua` существуют. | 54 / 54 PASS |
| `lua5.1 tests/run.lua` | Полный набор: миграции и схема 6, автосъёмка, шагомер, дневник, достижения, настройки, журнал изменений. | 112 / 112 PASS |

`tests/mock_wow.lua` — фальшивый клиент (функции и фреймы WoW), на нём работают оба набора.
Перед сборкой релиза оба набора должны проходить полностью.

## 2. В клиенте Forever — чек-лист
Отмечайте по ходу игры. Если что-то не так — скриншот и `/fm diag`.

**Установка и окно**
- [ ] Аддон есть в списке, нет ошибок Lua при входе; `/fm` открывает окно, Esc закрывает.
- [ ] Свои текстуры и шрифты видны (нет зелёных квадратов); русский и английский переключаются.
- [ ] Окно перетаскивается, масштаб и размер сохраняются после `/reload`.

**Автосъёмка**
- [ ] Новый уровень, смерть, босс, дуэль, редкий/эпический/легендарный предмет, новая зона,
      гильдия — снимок появляется в `_forever_/Screenshots` и в Истории.
- [ ] Чистый кадр прячет интерфейс и возвращает его; `/fm ui` возвращает в аварийном случае.
- [ ] Пассивный снимок через выбранный интервал активной игры; в AFK и бою время не идёт.

**Уведомления**
- [ ] Мини, открытие и легендарное выглядят ровно: фон внутри рамки, «x» внутри рамки.
- [ ] «Показать» — показывает и прячет образец; «Изменить» — место, размер, масштаб сразу применяются.

**История и данные**
- [ ] Все восемь разделов открываются; выбор персонажа и «Все персонажи» работают.
- [ ] Шаги: пробежка 30 с по прямой ≈ 210 ярдов ≈ 128 шагов.
- [ ] После `/reload` и перезахода всё сохранено; резервная копия → импорт возвращает данные.

## 3. API клиента: что известно
Клиент Viktor: Forever 1.60.1, build 71037, `GetBuildInfo()` → 16001 (совпадает с TOC), Linux (Wine).

| Что | Состояние |
|---|---|
| `Screenshot()`, `SCREENSHOT_STARTED/SUCCEEDED` | работают (spike v0.0.1): успех приходит асинхронно, ~0,08 с, в бою тоже; `FAILED` вызвать не удалось |
| `GetBuildInfo`, `C_Timer.After/NewTimer/NewTicker`, `InCombatLockdown`, `UnitLevel`, `GetMaxPlayerLevel`, `GetRealZoneText`, `C_Map.GetBestMapForUnit`, `C_Map.GetPlayerMapPosition`, `IsInInstance`, `issecretvalue`, `C_EventUtils.IsEventValid`, `C_AddOns.GetAddOnMetadata`, `GetLocale` | есть в клиенте |
| `UnitPosition`, `GetUnitSpeed`, `IsSwimming/IsFlying/UnitOnTaxi/UnitInVehicle` | не проверено; при secret или `nil` шаги не считаются |
| `RequestTimePlayed` / `TIME_PLAYED_MSG` | не проверено; без них показывается своё время активной игры |
| `UnitIsAFK` | есть; поведение при `/afk` не проверено (без него персонаж считается не-AFK) |
| `UnitGUID("player")` | не проверено, стабилен ли между сессиями |

Ключ персонажа — `Сервер:Имя`, а не GUID: сообщество пишет, что GUID в Forever обфусцированы,
и ключ по GUID мог бы терять историю. GUID сохраняется и сверяется: `/fm debug` → строка
Character покажет `(changed!)`, если он изменился. `/fm debug` также перечисляет функции,
которых нет в клиенте.
