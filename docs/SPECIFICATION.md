# Спецификация ForeverMemories v0.5.0 — UX Update & Step Tracker

Источник: ТЗ автора от 2026-11-24 и пять визуальных макетов. Это ТЗ имеет приоритет над всеми
предыдущими требованиями: старые пункты, которые ему противоречат, неактуальны.
Целевая игра — исключительно **World of Warcraft: Forever**.

Главный принцип: **установил, зашёл в игру, всё работает автоматически.** Никаких профилей,
пресетов, алгоритмов и технических параметров в интерфейсе. Автосъёмка — основная функция,
шагомер — дополнительная.

## 1. Интерфейс
- Четыре вкладки сверху: **Главная, Автосъёмка, История, Настройки**. Вкладок «События»,
  «Съёмка», «Путешествие», «Профили», «Диагностика», «Об аддоне» нет.
- Шапка на всех вкладках: иконка, «ForeverMemories», слоган *Your adventure. Your story.*,
  индикатор (зелёный «Активен» / серый «На паузе»), кнопка паузы, кнопка закрытия.
  Пауза останавливает только автосъёмку, не шагомер.
- Низ окна: «World of Warcraft: Forever», версия, `/fm`.

## 2. Главная
- Имя текущего персонажа, иконка класса (если API даёт), подпись «Статистика текущего персонажа».
- Карточки 2×2: Всего снимков · Снимков сегодня · Локаций (уникальные зоны со снимками) · Шагов сегодня.
  Только текущий персонаж, данные других не суммируются.
- Пять последних успешных снимков: иконка события, название, локация, дата и время, доп. информация.
  Кнопка «Посмотреть все снимки» → История / Снимки. Пусто: «У этого персонажа пока нет снимков».
- Миниатюр нет (API не умеет), вместо них иконки событий.

## 3. Автосъёмка
- **Как фотографировать:** Обычный кадр (с интерфейсом, по умолчанию) / Чистый кадр (без интерфейса).
  Если чистый кадр небезопасен (бой) — обычный. Интерфейс в бою не скрывается. После снимка
  восстанавливается исходное состояние; интерфейс, скрытый игроком, не включается.
  Двойной режим и серии удалены.
- **Когда фотографировать:** девять галочек, все включены по умолчанию, без категорий и настроек событий.

| Событие | Условие |
|---|---|
| Новый уровень | каждый уровень, включая максимальный (не отдельное событие) |
| Смерть | смерть текущего персонажа |
| Победа над боссом | успешный бой с боссом подземелья или рейда, без косвенных догадок |
| Победа в дуэли | только победа текущего персонажа |
| Редкий / Эпический / Легендарный предмет | фактическое получение, качество 3 / 4 / 5, без дублей |
| Новая зона | первое посещение зоны этим персонажем |
| Вступление в гильдию | фактическое вступление; вход в игру — не вступление |

Недоступное в клиенте событие показывается неактивным с подсказкой. Ложных срабатываний нет.

Внутри ядра автоматически (в UI не выводится): задержки и приоритеты событий, очередь, защита от
дублей и частых снимков, от экранов загрузки, защита UI в бою, восстановление UI, обработка
ошибок, отмена устаревших запросов, объединение совместимых событий. Один снимок на событие.

## 4. Шагомер (Step Tracker)
- Работает всегда, независимо от автосъёмки. В UI — только шаги (никаких метров, ярдов, км).
- **Считается:** ходьба, бег, автобег, наземный маунт, наземные формы друида, движение в бою.
- **Не считается:** телепорты, камень возвращения, такси, полёты, корабли, дирижабли,
  автоматический транспорт, плавание, бездействие, загрузки, скачки координат, время вне игры.
- Формула: **шаги = корректно измеренное расстояние (м) / 1,5** (решение автора 2026-11-24, v0.5.1;
  в исходном ТЗ было 0,75 м — короткое нажатие W давало +1…2 шага). Для маунта — тот же расчёт.
  Подсказка: «Количество шагов рассчитывается приблизительно на основе перемещения персонажа».
- Дробная часть накапливается, показывается целое число. Настройки длины шага нет.
- День начинается в 00:00 по часам компьютера. У каждого дня своя запись; переход через полночь
  без перезахода; измерения на границе суток идут в свой день; пропущенные дни не заполняются;
  выход, `/reload` и повторный вход не обнуляют; шаги персонажей не смешиваются.
- Числа с разделением разрядов, без сокращений (12 458, не 12,4K), русские склонения.

## 5. История
- Имя текущего персонажа сверху, два подраздела: **Снимки** (по умолчанию) и **Шаги**.
- Снимки: группы по датам (новые сверху) с количеством за день; иконка, событие, локация, время,
  доп. информация; прокрутка без страниц, без тысяч одновременных элементов. Внизу:
  «Фотографии сохраняются в игровой папке Screenshots». Файлы аддон не трогает.
- Шаги: «Всего шагов»; столбчатый график за 7 календарных дней (сегодня — золотой, остальные
  приглушённые, подсказка с датой и числом, день без шагов — нулевой высоты); ежедневный список
  (новые сверху). Без рекордов, целей, калорий.

## 6. Настройки
Кнопка на миникарте (вкл) · Уведомления о снимках (вкл) · Звуковое сопровождение (выкл) ·
Язык (автоматически) · Масштаб окна (100%) · кнопка «Восстановить положение окна».
Диагностика — только slash-команды (`/fm status`, `/fm debug`, `/fm log`); аварийная `/fm ui`.

## 7. Миникарта
Перемещение по окружности, сохранение положения, скрытие в настройках, индикация паузы.
ЛКМ — окно, ПКМ — пауза, СКМ — ручной снимок (выбранный режим, общее ядро).
Подсказка: название, состояние, персонаж, снимков сегодня, шагов сегодня, управление.

## 8. Уведомления
После успешного автоматического снимка: «Снимок сохранён» + событие («Получен 24-й уровень»).
Не попадает в снимок, исчезает сам, отключается, звук по настройке. У шагомера уведомлений нет.

## 9. Данные
- Общие для аккаунта: состояние автосъёмки, режим, события, уведомления, звук, миникарта,
  язык, масштаб, положение окна.
- Отдельно для персонажа: идентификатор, имя, сервер, класс, история снимков, счётчики
  (всего, по дням), уникальные зоны со снимками, посещённые зоны, шаги всего и по дням.
- Счётчики растут только после подтверждения снимка игрой. Чужие скриншоты не учитываются.
- SavedVariables; сохранность при аварийном завершении клиента не гарантируется.

## 10. Миграция с 0.4.2-beta
Сохраняются история, статистика, совместимые настройки, посещённые зоны. Структура
версионирована, миграция однократная и без дублей. Записи с неизвестным владельцем никому не
присваиваются. Шаги за период до установки шагомера не создаются.

## 11. Производительность и безопасность
События для автосъёмки, отдельный таймер для шагомера, без сканирования мира и лишних таймеров,
без перерисовки всего окна на каждый шаг, без вмешательства в управление и камеру, без обхода
ограничений Blizzard и Secret Values, без внешних сервисов. Ошибка одного модуля не
останавливает другой.

## 12. Решения при реализации (отступления с обоснованием)

| Пункт ТЗ | Решение | Почему |
|---|---|---|
| 12.3 «предпочтительно GUID» | Ключ персонажа — `Сервер:Имя`; GUID сохраняется и сверяется | По данным сообществ GUID в Forever обфусцированы; если GUID меняется между сессиями, ключ по GUID терял бы историю при каждом входе. `Сервер:Имя` уникален на сервере, а старые записи 0.4.2 уже содержат этот ключ, поэтому миграция точная. Смена GUID при том же имени отмечается (`/fm debug`). После проверки стабильности GUID в клиенте ключ можно сменить в следующей версии. |
| 6.4 интервал 0,5 с | Оставлен 0,5 с | Один лёгкий таймер; на стоянии работа заканчивается после проверки скорости. Оптимизация — после замеров в клиенте. |
| 6.4 резервный расчёт по скорости | Включён только если клиент сообщает такси, транспорт, полёт и плавание | Скорость `GetUnitSpeed` — собственная скорость персонажа; на корабле она 0, поэтому транспорт не считается. Если хоть одна проверка недоступна или secret — шаги не считаются. |
| 14.3 окно 620×580 | 620×640 | В 580 не помещаются карточки 2×2 и пять последних снимков без наложения. Окончательно — после проверки в клиенте. |
| 5.3 предметы | По строке чата «Вы получили…» (`CHAT_MSG_LOOT`) | Игра пишет её только при получении, не при перекладывании. Покупка у торговца и награда за задание — тоже получение. |
