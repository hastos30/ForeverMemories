# UI/UX
Нативный WoW-интерфейс: тёмный фон #10100F, панели #282116, золото #C9A35E, текст #E8DCC0, активность #7CAA66. Игровые шрифты, читаемые подписи и статусы не только цветом. Основное окно ориентировочно 800×560, масштабируемое 0.8–1.5, перемещаемое, с сохранением позиции и безопасным сбросом за пределами экрана.

```
┌ ForeverMemories ─────────── [Автосъёмка: ВКЛ] [×] ┐
│ Главная       │ Профиль: Minimalist       [▼]    │
│ События       │ Всего 128 | Сегодня 12 | Зон 8   │
│ Съёмка        │ Последние воспоминания           │
│ Путешествие   │ ✓ 18:42 Новый уровень           │
│ Журнал        │ ✓ 18:15 Новая зона              │
│ Профили       │ [Сделать кадр] [Пауза]           │
│ Настройки     │                                  │
│ Диагностика   │ Forever • v0.1.0 • /fm          │
└──────────────────────────────────────────────────┘
```
Главная: реальная статистика, статус/причина паузы, последние 5 записей, кнопки ручного кадра и пресета. Никаких фиктивных цифр в релизе.
События: категории, чекбоксы, статус доступности API, раскрываемый редактор задержки (0–10 с), циклов (1–5), интервала (1–10 с), режима, приоритета (1–4), cooldown (0–120 с), первого раза. Простой режим показывает только переключатели; расширенный — все поля.
Съёмка: режим по умолчанию, серия, ограничения, безопасный fallback, подписи, тестовый кадр. Путешествие: интервал, случайный режим, фильтры, лимиты. Журнал: таблица время/событие/персонаж/зона/статус, детали записи, заметка, избранное, фильтры, удаление с подтверждением. Профили: выбор, копирование, переименование, удаление пользовательского профиля, сброс с подтверждением. Встроенные пресеты неизменяемы; изменение создаёт Custom. Настройки: язык auto/RU/EN, миникарта, звук, уведомления, масштаб. Диагностика: сборка клиента, доступность API, состояние FSM, очередь, журнал ошибок, тестовый кадр. Об аддоне: версия, автор (заполнить при релизе), лицензия, ссылки.
Миникарта: ЛКМ окно, ПКМ пауза/возобновление, СКМ ручной кадр; перетаскивание и скрытие. Tooltip показывает статус и число успешных кадров сегодня.
Уведомление после восстановления UI и подтверждения: «Воспоминание сохранено», событие, зона; при отсутствии подтверждения — нейтральный статус. Настройки позиции, времени (1–5 с), масштаба, звука. Не попадать в следующий кадр: скрывать собственные уведомления перед подготовкой съёмки.
Ручная панель: режим, таймер, серия, подпись, кнопка снимка, отмена таймера. Панель скрывается на время съёмки. Все действия и ошибки локализованы. При первом запуске короткий выбор пресета, без обязательного мастера настройки.
