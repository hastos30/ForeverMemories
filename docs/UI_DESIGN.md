# Дизайн интерфейса (v0.5.0)

Основа — пять макетов автора (Главная, Автосъёмка, История/Снимки, История/Шаги, Настройки).
Атмосфера Warcraft + минимализм: тёмные матовые поверхности, тонкие золотые рамки,
никаких ярко-красных кнопок.

## Окно
620×720 (ориентир ТЗ 620×580 увеличен по высоте; 640 → 720 в v0.6.0 для блока пассивной
съёмки, см. SPECIFICATION §12), отступ 16.
Перемещается за пустые места, сохраняет положение, не выходит за экран, масштаб 75–130%,
Esc закрывает.

## Вкладки
- **Главная (v0.8.0, Daily Adventure):** иконка класса 36, имя, «Приключение дня», дата справа;
  карточки 2×2 (290×80: иконка 18, число, подпись): снимков сегодня, шагов сегодня, локаций
  сегодня, в игре сегодня; блок 588×96: «Текущая локация» (иконка карты), разделитель,
  «Следующий пассивный снимок» + MM:SS справа, золотая полоса 3 px (фон полосы — цвет
  разделителя); «Последние снимки» — 3 строки по 36; ссылка «История снимков» внизу.
- **Автосъёмка:** две карточки режима 289×78 (выбранная: золотая рамка, фон #4A3B22, галочка);
  разделитель; «Когда фотографировать» + «N из 9»; девять галочек по 28. Недоступное событие —
  серое, причина в подсказке. Разделитель; «Пассивная съёмка» с иконкой часов
  (INV_Misc_PocketWatch_01); галочка; «Интервал между снимками»; четыре кнопки 76×24
  (15 / 30 / 45 / 60 мин., выбранная — как выбранная вкладка, при выключенной съёмке неактивны);
  серая подпись «Один дополнительный снимок каждые N минут активной игры».
- **История (v0.8.0, Lifetime Statistics):** иконка класса, имя, «Статистика за всё время»;
  те же карточки 2×2 (всего снимков, всего шагов, посещено локаций, игровых дней), видны всегда;
  три кнопки-подраздела 30 высотой (Снимки / Шаги / Локации); подраздел 588×310.
  Снимки: прокручиваемый список (строка 40: заголовок дня с количеством или карточка снимка),
  внизу заметка про папку Screenshots. Шаги: график 7 дней, список по дням, заметка о расчёте.
  Локации: строка 40 — заголовок дня («N локаций») или карточка зоны (иконка карты, имя,
  зелёное «Первое посещение», время).
- **Настройки:** три галочки, разделитель, язык (выпадающий список справа), масштаб (значение
  справа, ползунок), кнопка «Восстановить положение окна» во всю ширину.

## Элементы (`UI/Widgets.lua`)
`W.Button` (плоская, выделение и наведение), `W.Check`, `W.Dropdown`, `W.Slider`, `W.Icon`,
`W.IconBox`, `W.Divider`, `W.Dot`, `W.Link`, `W.ScrollList` (переиспользует строки),
`W.Tooltip` (подсказка у каждого интерактивного элемента). Только простые фреймы,
`BackdropTemplate` и цветные текстуры.

Текст в одну строку (`SetWordWrap(false)`): длинное обрезается многоточием, не налезает на соседей.
